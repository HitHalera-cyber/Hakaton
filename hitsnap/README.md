# HitSnap — угадай песню за секунду

Десктопная игра (Windows / macOS / Linux): звучит **1 секунда** песни — угадайте её. Не получилось — слушайте **3 секунды**, потом **5 секунд**. Ответ ищется в живой строке поиска по всей базе: набираете `mick` — сразу видите всё похожее.

## Возможности

- **Около 700 популярных песен** — зарубежные хиты с 60-х до 2024 года, русский рок, поп и рэп. Звук — официальные 30-секундные превью Deezer (запасной вариант — iTunes), скачиваются по требованию и кешируются на диске: уже прослушанные песни работают без интернета.
- **Лестница 1 → 3 → 5 секунд.** Неверный ответ или «Дальше» открывают отрывок подлиннее. Отрывок начинается в случайном месте превью и проигрывается точно до доли секунды (Web Audio).
- **Умный живой поиск:** по началу слов названия и исполнителя, с опечатками (`bohemain rapsody`), транслитом (`kino` → «Кино») и даже в неправильной раскладке (`rbyj` → «Кино»). ↑/↓ и Enter — без мыши.
- **Режимы:** Классика (5–20 раундов), Выживание (3 жизни), Песня дня (5 песен, одинаковых для всех сегодня), Тренировка.
- **Очки:** 1000 / 500 / 250 за 1-ю / 2-ю / 3-ю попытку, бонус за серию (до ×1,5), подсказки (год выпуска, первая буква исполнителя) снимают по 20%.
- **«Исполнитель верный!»** — если угадан артист, но не песня, игра подскажет.
- **Сложность:** лёгкая 2/5/10 с, обычная 1/3/5 с, хардкор 0,5/1/3 с.
- **Фильтры:** десятилетия, жанры, язык.
- **Разбор после раунда:** обложка, альбом, год, песня продолжает играть; ссылка «Слушать целиком».
- **Статистика и 15 достижений:** распределение по попыткам, рекорды по режимам, история игр, лучшая серия.
- **Библиотека:** вся база с отметками «угадана / с ошибками / ещё не звучала», прослушивание превью и **добавление своих песен** из каталога Deezer.
- **Тёмная, светлая и системная темы**, 5 акцентных цветов, анимированный визуализатор спектра, звуковые эффекты.
- Горячие клавиши: `Пробел` — повторить отрывок, `Esc` — дальше, `Ctrl+H` — подсказка, `Enter` — следующая песня.

## Запуск

Нужен Node.js 20+.

```bash
cd hitsnap
npm install
npm run dev        # приложение с горячей перезагрузкой
```

Сборка установщика:

```bash
npm run dist:win   # release/HitSnap-1.0.0-x64-nsis.exe и portable .exe
npm run dist:mac   # .dmg
npm run dist:linux # .AppImage
```

Для Windows установщик и portable-версию также собирает GitHub Actions (`.github/workflows/hitsnap-windows.yml`) — их можно скачать из артефактов запуска.

Остальные команды:

```bash
npm test           # тесты (поиск, правила игры, выбор превью)
npm run typecheck
npm run dev:web    # интерфейс в браузере с синтезированными мелодиями вместо песен
```

## Архитектура

```
hitsnap/
  src/
    shared/                  общий код main ⇄ renderer
      types.ts               Song, ResolvedTrack, контракт IPC (HitSnapApi)
      catalog.ts             встроенная база песен
    main/                    процесс Electron (Node)
      index.ts               окно, IPC-обработчики
      services/
        providers.ts         поиск превью: Deezer → iTunes, каталог для «Моих песен»
        match.ts             отсев караоке/каверов, выбор нужной записи
        audioCache.ts        дисковый кеш превью (400 МБ, LRU)
        storage.ts           JSON-хранилище настроек и статистики
        http.ts              net.fetch с таймаутом
    preload/index.ts         безопасный мост window.hitsnap (contextIsolation + sandbox)
    renderer/src/            React-интерфейс
      lib/                   чистая логика без UI
        game.ts              режимы, стадии, очки, очередь песен
        search.ts, text.ts   живой поиск, транслит, раскладка, опечатки
        audio.ts             Web Audio: точные отрывки, анализатор, звуки
        achievements.ts      достижения
        api.ts               доступ к main-процессу (+ демо-бэкенд для браузера)
      store/                 состояние (zustand)
        game.ts              машина состояний игры
        stats.ts, settings.ts, library.ts — сохраняются на диск
      components/            UI-кит, поиск, визуализатор, шкала 1/3/5 с
      screens/               Главная, Игра, Библиотека, Статистика, Настройки
  tests/                     vitest
```

Стек: Electron, electron-vite, React 19, TypeScript, Tailwind CSS 4, Framer Motion, Zustand, lucide-react.

Данные пользователя хранятся в папке профиля приложения (`%APPDATA%/HitSnap` в Windows): `hitsnap-data.json` и `audio-cache/`.
