# HitSnap — угадай песню за секунду

Десктопная игра (Windows / macOS / Linux): звучит **1 секунда** песни — угадайте её. Не получилось — слушайте **3 секунды**, потом **5 секунд**. Ответ ищется в живой строке поиска по всей базе: набираете `mick` — сразу видите всё похожее.

## Возможности

### Песни
- **4 860 песен в базе, 17 жанров:** поп, рок, метал, инди, электроника, диско, хип-хоп, R&B, джаз и блюз, кантри, латино, K-pop и J-pop, музыка из кино и игр, русская эстрада, русский рок, русский рэп, советская эстрада. Звук — официальные 30-секундные превью Deezer (запасной вариант — iTunes), скачиваются по требованию и кешируются на диске: уже прослушанные песни работают без интернета. Песни без превью игра пропускает и запоминает на 2 недели.
- **Известность песен:** у каждой песни есть уровень — мега-хит, популярная или для знатоков. Можно играть «Только хиты», «Популярное», «Всё подряд» или «Для знатоков».
- **Плейлисты Deezer:** вставьте ссылку на любой публичный плейлист — и играйте только в него. Чарт Deezer (топ-100) загружается одной кнопкой.
- **Своя музыка:** выберите папку с mp3 / m4a / flac / ogg — игра загадает ваши песни (название берётся из имени файла «Исполнитель - Название»).
- **Свои песни поштучно** — поиск по каталогу Deezer в «Библиотеке».

### Как звучит отрывок
- **Лестница 1 → 3 → 5 секунд.** Неверный ответ или «Дальше» открывают отрывок подлиннее. Сложность: лёгкая 2/5/10 с, обычная 1/3/5 с, хардкор 0,5/1/3 с.
- **«Случайный момент» или «С начала».** В режиме «С начала» отрывок играет с первой ноты записи (тишина в начале пропускается). Для своей музыки это настоящее начало песни. Для встроенной базы — начало 30-секундного фрагмента, который даёт Deezer: сервисы не отдают песню целиком, поэтому самое начало песни доступно только для своей музыки.

### Режимы
- **Классика** (5–20 раундов), **Выживание** (3 жизни), **Песня дня** (5 песен, одинаковых для всех сегодня, со счётчиком дней подряд), **Тренировка**.
- **Викторина** — 4 варианта ответа, похожие по жанру и годам (клавиши 1–4).
- **Угадай год** — назовите год выхода песни: точный ответ — полные очки, ошибка в 1–2 года тоже засчитывается.
- **Вечеринка** на 2–4 игроков за одним компьютером: звучит отрывок, кто узнал — жмёт свою клавишу (1–4) и ищет песню; ошибся — отвечают остальные, а отрывок становится длиннее. В конце — пьедестал.

### Подборки
- **Жанровые станции:** 17 карточек жанров и «Случайный жанр» — один клик, и игра идёт только в этом жанре.
- **Эпохи:** 60-е … 2020-е.
- **Избранное** (сердечко на любой песне), **Работа над ошибками** (песни, которые вы не угадали в последний раз), **Мои песни**, плейлисты, своя музыка.
- Для подборок можно выбрать режим: классика, викторина, угадай год или выживание.

### Прогресс
- **Уровни:** очки копятся в опыт, от «Новичка» до «Легенды».
- **Статистика:** с какой попытки угадываете, точность по жанрам, рекорды по режимам, история игр, серия дней «Песни дня».
- **20 достижений.**
- **«Поделиться»:** результат копируется строкой с квадратиками, как в Wordle: `🟩🟨⬛🟩🟧`.

### Остальное
- **Умный живой поиск:** по началу слов названия и исполнителя, с опечатками (`bohemain rapsody`), транслитом (`kino` → «Кино») и даже в неправильной раскладке (`rbyj` → «Кино»).
- **Очки:** 1000 / 500 / 250 за 1-ю / 2-ю / 3-ю попытку, бонус за серию (до ×1,5), подсказки снимают по 20%. «Исполнитель верный!» — если угадан артист, но не песня.
- **Тёмная, светлая и системная темы**, 5 акцентных цветов, визуализатор спектра, звуковые эффекты.
- Горячие клавиши: `Пробел` — повторить отрывок, `Esc` — дальше, `Ctrl+H` — подсказка, `Enter` — следующая песня, `1–4` — варианты викторины и «кнопки» игроков на вечеринке.

## Установка (Windows)

1. Откройте вкладку **Actions** репозитория → workflow **HitSnap Windows build** → последний успешный запуск.
2. Внизу страницы, в разделе **Artifacts**, скачайте **HitSnap-windows** и распакуйте архив.
3. Запустите **`HitSnap-Setup-1.1.0.exe`** — установщик на русском: можно выбрать папку, он создаст ярлыки на рабочем столе и в меню «Пуск». Удалить игру можно через «Приложения» Windows.

Не хотите устанавливать — рядом лежит **`HitSnap-Portable-1.1.0.exe`**, он запускается без установки.

> Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать «Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.

## Запуск из исходников

Нужен Node.js 20+.

```bash
cd hitsnap
npm install
npm run dev        # приложение с горячей перезагрузкой
```

Сборка установщика:

```bash
npm run dist:win   # release/HitSnap-Setup-1.1.0.exe и HitSnap-Portable-1.1.0.exe
npm run dist:mac   # .dmg
npm run dist:linux # .AppImage
```

Для Windows установщик и portable-версию также собирает GitHub Actions (`.github/workflows/hitsnap-windows.yml`) — их можно скачать из артефактов запуска.

Остальные команды:

```bash
npm test           # тесты (поиск, правила игры, выбор превью)
npm run typecheck
npm run dev:web    # интерфейс в браузере с синтезированными мелодиями вместо песен
```

## Архитектура

```
hitsnap/
  src/
    shared/                  общий код main ⇄ renderer
      types.ts               Song, ResolvedTrack, контракт IPC (HitSnapApi)
      catalog/               встроенная база песен: data/<жанр>.ts, строка «Исполнитель | Название | Год | уровень»
    main/                    процесс Electron (Node)
      index.ts               окно, IPC-обработчики
      services/
        providers.ts         поиск превью: Deezer → iTunes; каталог, плейлисты и чарт Deezer
        localMusic.ts        своя музыка: выбор папки и сканирование (читаются только выбранные папки)
        trackName.ts         «Исполнитель - Название» из имени файла
        match.ts             отсев караоке/каверов, выбор нужной записи
        audioCache.ts        дисковый кеш превью (400 МБ, LRU)
        storage.ts           JSON-хранилище настроек и статистики
        http.ts              net.fetch с таймаутом
    preload/index.ts         безопасный мост window.hitsnap (contextIsolation + sandbox)
    renderer/src/            React-интерфейс
      lib/                   чистая логика без UI
        game.ts              режимы, стадии, очки, очередь песен, варианты викторины, известность
        progress.ts          уровни, серия дней, строка «Поделиться»
        search.ts, text.ts   живой поиск, транслит, раскладка, опечатки
        audio.ts             Web Audio: точные отрывки, анализатор, звуки
        achievements.ts      достижения
        api.ts               доступ к main-процессу (+ демо-бэкенд для браузера)
      store/                 состояние (zustand)
        game.ts              машина состояний игры (все режимы, включая вечеринку)
        launch.ts            запуск игры с настройками игрока
        stats.ts, settings.ts, library.ts — сохраняются на диск
      components/            UI-кит, поиск, визуализатор, шкала 1/3/5 с
      screens/               Главная, Подборки, Игра, Библиотека, Статистика, Настройки
  tests/                     vitest
```

Стек: Electron, electron-vite, React 19, TypeScript, Tailwind CSS 4, Framer Motion, Zustand, lucide-react.

Данные пользователя хранятся в папке профиля приложения (`%APPDATA%/HitSnap` в Windows): `hitsnap-data.json` и `audio-cache/`.
