# Гитарные аккорды

Десктопное приложение: интерактивный гриф гитары, определение аккорда по точкам нажатия (или по нотам с MIDI-клавиатуры), буквенное название, русская расшифровка и звучание аккорда.

![Скриншот](docs/screenshot.png)

## Возможности

| Раздел | Что реализовано |
|---|---|
| **Гриф** | 6 струн, 15 ладов, строи Standard и Drop D; клик ставит/снимает точку, на одной струне можно поставить несколько точек; отметки у порожка O (открытая) / X (заглушена): клик по циклу O → X → пусто, правый клик — заглушить струну; подсветка клетки и подсказка с нотой (например, «A3 · Ля, 4-я струна, 7 лад»); «Очистить все точки»; горизонтальный и вертикальный вид; ноты на грифе (вкл/выкл); подписи в точках: название ноты или ступень аккорда; тоника выделена красным |
| **Определение** | Буквенное обозначение (C, Am, G7, Fmaj7, F#m, Bb, Cadd9, Bm7b5, C/E…), русская расшифровка («Соль мажорный септаккорд», «До мажор, бас Ми — секстаккорд (1-е обращение)»), состав нот со ступенями (F – A – C – E), звучащие ноты с октавами; другие трактовки (C6 ↔ Am7/C); «Неизвестный аккорд» с ближайшими вариантами; одиночная нота и интервалы («Интервал: большая терция») |
| **Звук** | Синтез щипковой струны (Карплус — Стронг с дробной задержкой, резонансами корпуса и реверберацией); три тембра: акустика, нейлон, электрогитара; бой (почти одновременно) и перебор с регулируемой скоростью; громкость; «Стоп»; автоматическое проигрывание при изменении точек |
| **MIDI** | Автоопределение устройств и подключение «на лету»; выбор устройства или «все устройства»; Note On / Note Off (включая Note On с velocity 0), All Notes Off; ноты с клавиатуры подсвечиваются на всех позициях грифа, ноты вне диапазона гитары помечаются; аккорд определяется по нотам с клавиатуры; фиксация аккорда после отпускания клавиш; «⇩ На гриф» — подбор удобной аппликатуры; экранная мини-клавиатура для работы без MIDI |
| **Дополнительно** | История определённых аккордов (клик — восстановить); избранные аппликатуры (сохранить, переименовать, удалить, загрузить); тёмная и светлая темы; режим «одна нота на струне» (как на настоящей гитаре — звучит только верхний зажатый лад); все настройки сохраняются между запусками |

Горячие клавиши: **Пробел** — сыграть, **Esc** — остановить звук, **Delete** — очистить гриф, **F12** — инструменты разработчика.

## Архитектура

Стек: **Electron + React + TypeScript + Vite**, звук — Web Audio API, MIDI — Web MIDI API, сборка дистрибутивов — electron-builder.

```
┌───────────────── Electron main (electron/main.cjs) ─────────────────┐
│  окно, разрешение 'midi', автовоспроизведение звука без жеста       │
└──────────────────────────────┬──────────────────────────────────────┘
                               │ загружает dist/index.html
┌──────────────────── Renderer (React, src/) ─────────────────────────┐
│                                                                     │
│  UI (components/)         App.tsx — состояние и связи               │
│   Fretboard (SVG) ───────► board ─┐                                 │
│   Piano / MidiPanel ◄──── midi ───┼──► soundingNotes ─► detectChord │
│   ChordDisplay ◄──────────────────┘          │             │        │
│   SoundPanel ──► audio/guitarSynth ◄─────────┘             │        │
│   SidePanels (история, избранное) ◄────────────────────────┘        │
│                                                                     │
│  music/  — чистая логика без UI (покрыта тестами)                   │
│  audio/  — синтез струны, эффекты, бой/перебор                      │
```

Логика отделена от интерфейса: всё, что касается нот, аккордов и аппликатур, — это чистые функции в `src/music/`, которые тестируются без браузера.

### Как определяется аккорд

1. Из грифа собираются звучащие ноты (открытые струны + зажатые лады, без заглушённых струн); в режиме «одна нота на струне» — только верхний лад на каждой струне. Если зажаты клавиши MIDI-клавиатуры, берутся их ноты.
2. Ноты сводятся к высотным классам (0 = C … 11 = B); самая низкая нота — бас. Поэтому любые аппликатуры и обращения одного аккорда распознаются одинаково.
3. Каждая нота по очереди пробуется как тоника; интервалы от неё сравниваются с ~35 шаблонами (мажор, минор, dim, aug, sus2/4, 5, 6, m6, 7, maj7, m7, m7b5, dim7, add9, 9, maj9, m9, 7b9, 7#9, 11, 13…). У шаблона есть обязательные и пропускаемые ступени (например, квинта в септаккорде).
4. Оценка: точное совпадение, бонус за тонику в басу, штраф за пропущенную ступень и небольшой вес популярности аккорда. Поэтому `C E G A` с басом C — это C6, а с басом A — Am7.
5. Если тоника не в басу, название пишется через «/» (C/E) и в расшифровке называется обращение: секстаккорд / квартсекстаккорд для трезвучий, квинтсекстаккорд / терцквартаккорд / секундаккорд для септаккордов.
6. Ноты записываются по ступеням от тоники (Bb – D – F, а не A# – D – F; Adim7 = A – C – Eb – Gb).
7. Если точного совпадения нет — «Неизвестный аккорд» и ближайшие варианты (одна лишняя нота или нет терции/квинты), например `C(+C#)`.

### Звук

Звук синтезируется, файлы сэмплов не нужны. Для каждой ноты один раз рассчитывается буфер: шумовой «щипок» (с фильтром яркости и учётом места щипка) проходит через линию задержки длиной в период ноты с затухающим сглаживающим фильтром. Дробная задержка даёт точность строя лучше 5 центов (проверяется тестом). Дальше сигнал проходит через резонансы корпуса, свёрточную реверберацию и компрессор. «Бой» — ноты от баса вверх с шагом 18 мс, «перебор» — с настраиваемым шагом.

## Запуск и сборка

Нужен Node.js 20+ (только для разработки: конечному пользователю ничего устанавливать не нужно).

```bash
cd guitar-chords
npm install
npm run dev        # режим разработки (Vite + Electron с горячей перезагрузкой)
npm test           # тесты
npm run build      # проверка типов и сборка интерфейса в dist/
npm start          # запуск собранного интерфейса в Electron
```

### Дистрибутивы

```bash
npm run dist:win     # Windows: release/GuitarChords-Setup-1.0.0.exe (установщик) и GuitarChords-Portable-1.0.0.exe
npm run dist:mac     # macOS:   release/*.dmg
npm run dist:linux   # Linux:   release/*.AppImage
```

Каждый дистрибутив включает Electron, поэтому пользователю не нужны Node.js и другие рантаймы. Windows-установщик собирается на Windows; на Linux для этого нужен Wine. В репозитории есть GitHub Actions workflow (`.github/workflows/guitar-chords.yml`): он запускает тесты и собирает установщики для Windows, macOS и Linux, а готовые файлы выкладывает в артефакты сборки.

### MIDI

MIDI-клавиатуру можно подключить до или после запуска: список устройств обновляется автоматически. На Windows работает любая class-compliant USB-MIDI клавиатура. Если MIDI-подсистема ОС недоступна, приложение показывает это и предлагает «Повторить поиск». Без клавиатуры аккорд можно собрать на экранной мини-клавиатуре.
