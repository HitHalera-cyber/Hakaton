# Тестовые чертежи

Сгенерированы программно (`generator/`): DXF с рамкой, основной надписью и
размерами по ГОСТ → PDF в стиле экспорта КОМПАС (штрихи осевых отдельными
отрезками, окружности хордами). Размеры на чертежах точные — по ним видно,
держит ли программа каждое число.

| Файл | Деталь | Что проверяет |
|---|---|---|
| plita.pdf | Плита 120×80×12, 1:1 | выдавливание; толщина по виду сбоку; 4 отверстия, окно R5, скругления R8 |
| kronshtein.pdf | Кронштейн Г-образный, 1:1 | выбор главного вида (не прямоугольник вида сверху); толщина 40 по виду сверху |
| prokladka.pdf | Прокладка 90×50, 1:1 | толщина по надписи «s2»; Ø30 и 4 отв. Ø6 |
| planka.pdf | Планка 70×45, 2:1 | фаска 30°, паз, R6; толщины на чертеже нет — берётся примерно |
| vtulka.pdf | Втулка Ø40/Ø25×50, 2:1 | тело вращения с отверстием (профиль не касается оси), фаски 1×45° |
| shaiba.pdf | Шайба Ø36/Ø17×3, 2:1 | короткая ось; таблица параметров 3×4 |
| val.pdf | Вал ступенчатый, 1:1 | тело вращения, фаски, шпоночный паз, сечение |
| flanets.pdf | Фланец, 1:2 | вид с торца с 6 отверстиями, полуразрез |

Сделать заново: `python generator/make_drawings.py out`,
`python generator/more_drawings.py out`, затем
`python generator/render_pdf.py out/plita.dxf plita.pdf --dash pieces --curves poly --arrows outline`.
