# КОМПАС-AI: восстановление чертежей в КОМПАС-3D v23

Плагин, который превращает PDF/изображение технического чертежа в редактируемый
чертёж КОМПАС-3D из настоящих объектов (отрезки, окружности, дуги, размеры, текст).

Проект независим от остального репозитория и ничего в нём не использует.

## Текущий этап: проверка API (шаг 3–4)

Целевые версии: КОМПАС-3D v22, v23, v24 (используем только API, доступный в v22).

Прежде чем писать распознавание, нужно убедиться, что выбранные методы API
работают в вашей версии КОМПАС. Для этого — скрипт `prototype/smoke_test.py`.

### Как запустить (Windows, нужен установленный КОМПАС-3D v23)

1. Установите Python 3.10+ с https://www.python.org (при установке отметьте
   «Add Python to PATH»).
2. Откройте командную строку (`Win+R` → `cmd`) и перейдите в папку прототипа:
   ```
   cd путь\к\Hakaton\kompas_ai_plugin\prototype
   ```
3. Установите зависимость:
   ```
   pip install -r requirements.txt
   ```
4. Запустите:
   ```
   py smoke_test.py
   ```
   КОМПАС откроется сам и создаст новый чертёж.

### Что должно получиться

- В КОМПАСе открыт чертёж с отрезком, окружностью, дугой, осевой линией,
  текстом, линейным размером и размером диаметра.
- Файл сохранён в `%TEMP%\kompas_ai_smoke\kompas_ai_smoke.cdw`.
- Рядом со скриптом появился `smoke_test_report.txt` — в нём по каждому шагу
  `[OK]` или `[FAIL]` с текстом ошибки.

**Пришлите содержимое `smoke_test_report.txt`** (и, если не трудно, скриншот
чертежа). По нему станет ясно, какие методы API подтверждены, а какие нужно
заменить.

## Что уже известно про API (КОМПАС v22, учебная лицензия истекла)

Работает через API5 (`ksDocument2D`):
- отрезки, окружности, дуги, точки, тексты, осевые (`ksLineSeg` со стилем 3);
- линейные размеры `ksLinDimension`: `ps` 0 — параллельный, 1 — вертикальный,
  2 — горизонтальный; число появляется при `ksDimTextParam.bitFlag = 1`;
- радиус `ksRadDimension` и диаметр `ksDiamDimension` (`ksRDimParam`);
- штриховка: `ksHatch(0, угол, шаг, 0, 0, 0)` → объекты границы → `ksEndObj()`;
- угловой размер `ksAngDimension` (`ksADimParam`: xc, yc, ang1, ang2, rad, dir; рисование — `ksDimDrawingParam`);
- новый документ нужного формата: `Document2D().ksCreateDocument(ksDocumentParam)`,
  `ksStandartSheet.format` 0–4 = A0–A4, `direct=True` — альбомный.

Не работает или не проверено:
- API7 `коллекция.Add()` и `LayoutSheets.Update()` без лицензии ничего не делают;
- вид с масштабом `ksCreateSheetView` без лицензии отклоняется (код 216) — пока рисуем
  в мм листа, а числа размеров пишем вручную.

Число размера вручную (`api_test4.py`): `bitFlag = 0`, `stringFlag = False`, строка
добавляется в `ksDynamicArray(GetTextArr())` элементом `ksChar255` (`ko_Char255`).
Значок Ø даёт `sign = 1`. С `stringFlag = True` строка не добавляется; `bitFlag = 1`
вместе со строкой даёт две строки (авто + ручная).
