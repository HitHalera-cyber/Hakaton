# Ядро распознавания (этап 1: векторный PDF)

Превращает векторный PDF чертежа в модель чертежа (Drawing IR) из настоящих
объектов: отрезки, окружности, дуги, осевые линии, размеры, тексты,
штриховки и геометрические связи. КОМПАС для этого не нужен: модель потом
передаётся в КОМПАС отдельным модулем записи.

## Запуск (Windows)

```
cd kompas_ai_plugin\core
py -m pip install -r requirements.txt
py -m kompas_ai.cli путь\к\чертежу.pdf
```

Если есть DXF того же чертежа, сохранённый из КОМПАС, можно сразу оценить точность:

```
py -m kompas_ai.cli чертёж.pdf --reference чертёж.dxf
```

Результаты появятся в папке `<имя>_result` рядом с PDF:

| Файл | Что это |
|---|---|
| `report.txt` | что найдено, что требует проверки, сравнение с эталоном |
| `preview.png` | исходный чертёж + распознанные объекты (цвета — в легенде) |
| `drawing.json` | модель чертежа — вход для записи в КОМПАС |
| `drawing.dxf` | тот же чертёж в DXF (можно открыть в КОМПАС или любой САПР) |

## Программа с окном (KompasAI.exe)

```
py -m pip install -r requirements.txt pyside6
py -m kompas_ai.gui
```

Открыть PDF (или перетащить в окно) → предпросмотр распознанного (колесо мыши —
масштаб, перетаскивание — сдвиг) → список «Требуют проверки» (щелчок показывает
объект на листе) → «Построить в КОМПАС» / «Сохранить DXF» / «Сохранить отчёт».

Сборка exe и установщика — автоматически на GitHub (Actions → «KOMPAS-AI Windows
build» → артефакты `KompasAI-Setup` и `KompasAI-portable`), вручную:
```
cd kompas_ai_plugin
pyinstaller packaging/KompasAI.spec --noconfirm
iscc packaging\installer.iss
```

## Построить чертёж в КОМПАС (Windows, КОМПАС v22–v24)

```
py -m kompas_ai.to_kompas путь\к\чертежу.pdf
```

КОМПАС откроется, в нём будет построен новый чертёж из настоящих объектов;
он же сохраняется рядом с PDF как `<имя>_kompas.cdw` (отчёт — `<имя>_kompas.txt`).
Можно передать и готовый `drawing.json`.

Масштаб:
- по умолчанию (`--mode sheet`) всё строится в мм листа, на своих местах; при
  масштабе не 1:1 числа размеров вписываются как на исходном чертеже — работает без лицензии;
- `--mode view` — вид с масштабом чертежа, КОМПАС сам считает размеры (нужна лицензия;
  если КОМПАС откажет, построение автоматически идёт в мм листа).

Модуль записи: `kompas/writer.py` (модель → команды), `kompas/api5.py` (команды → КОМПАС,
только вызовы, проверенные тестами в `prototype/`).

## Как это работает

| Шаг | Модуль |
|---|---|
| Чтение штрихов, заливок и текстов PDF, перевод в мм листа | `pdf/vector_extractor.py` |
| Формат листа, рамка, основная надпись, масштаб «5:1» | `semantics/sheet.py` |
| Склейка хорд в ломаные (КОМПАС режет каждую линию на хорды) | `geometry/chains.py` |
| Разбиение ломаных на отрезки, дуги, окружности (МНК) | `geometry/segmentation.py`, `geometry/fitting.py` |
| Стрелки (контур или растровая заливка) | `semantics/arrows.py` |
| Штриховка и её границы (грани контура) | `semantics/hatch.py`, `semantics/regions.py` |
| Осевые и штриховые линии из отдельных штрихов; короткие осевые | `geometry/linetypes.py`, `semantics/axes.py` |
| Размеры: текст + размерная линия + стрелки + выносные линии | `semantics/dimensions.py` |
| Масштаб по размерам и проверка каждого размера | `geometry/scaling.py` |
| Связи: совпадение, гориз./верт., параллельность, перпендикулярность, концентричность, касание | `geometry/constraints.py` |
| Модель чертежа (JSON) | `ir.py` |
| DXF, предпросмотр, отчёт, сравнение с эталоном | `export/`, `report/`, `evaluation/` |

Координаты в модели — миллиметры листа, начало в левом нижнем углу листа (как
у листа КОМПАС). Размер детали = размер на листе / масштаб.

## Точность: размеры главнее измерения

Координаты в PDF округлены (у КОМПАС — до ≈0,085 мм), поэтому измеренная геометрия
чуть отличается от задуманной: Ø10 выходит Ø9,99, угол 45° — 45,2°. По умолчанию
геометрия **выравнивается по размерам чертежа** (`geometry/regularize.py`):
почти горизонтальные/вертикальные линии становятся точными; координаты, связанные
размерами, решаются так, чтобы каждый размер был ровно равен надписи; окружности с
размером Ø/R получают точный радиус; стороны угловых размеров ставятся ровно на
написанный угол. Подписи размеров в КОМПАС — всегда значения с исходного чертежа.
Размер, противоречащий геометрии, не используется и попадает в «Требуют проверки».
Ключ `--raw` отключает выравнивание (геометрия как измерена в PDF).

## Уверенность и проверка

У каждого объекта есть `confidence`. Объекты ниже 0,8 попадают в список
«Требуют проверки» с объяснением. Размер, у которого надпись не совпадает с
геометрией (с учётом масштаба и округления), всегда отправляется на проверку.
Если масштаб в основной надписи и масштаб по размерам расходятся — выдаётся
предупреждение, ничего не исправляется молча.

## Тесты

```
py -m pytest
```

Тесты генерируют PDF с заранее известной геометрией (`tests/synthetic.py`) в двух
вариантах: окружности ломаными (как КОМПАС) и кривыми Безье (как другие САПР).

## Ограничения этапа 1

- Только векторный PDF (растр и сканы — этап 2).
- Все объекты помещаются в один вид; разделение на виды/разрезы — позже.
- Шероховатость, допуски формы, базы, выноски с текстом пока не распознаются.
- Координаты в PDF КОМПАС округлены до 1/300 дюйма (≈0,085 мм) — это предел точности входа.
